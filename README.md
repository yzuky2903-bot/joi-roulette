# Roleta JOI Casal (Tempo Real)

Roleta compartilhada + Chat online para casal.

- Quando um gira, **os dois veem a roleta girando**.
- Chat em tempo real.
- Botões separados: **Girar (Ele)** e **Girar (Ela)**.
- Código de sala privado.

---

## Como subir de graça (Replit - mais fácil)

1. Acesse: https://replit.com
2. Crie uma conta (pode usar Google)
3. Clique em **Create Repl**
4. Escolha **Node.js**
5. Apague os arquivos padrão
6. Faça upload de **todos os arquivos** desta pasta (arraste a pasta inteira ou suba um por um)
7. No terminal do Replit digite:
   ```
   npm install
   ```
8. Depois clique no botão **Run**
9. O Replit vai te dar um link tipo: `https://seu-projeto.seunome.repl.co`
10. Mande esse link pra ela.  
    Os dois entram, colocam o **mesmo código de sala** (ex: AMOR99) e pronto.

---

## Como usar

1. Abra o link
2. Digite seu nome
3. Escolha Homem ou Mulher
4. Coloque um código de sala (qualquer coisa, tipo `SAFADO` ou `AMOR123`)
5. Clique em **Entrar na Sala**
6. Mande o mesmo código pra ela
7. Quando os dois estiverem na sala, qualquer um pode girar a roleta
8. A roleta gira na tela dos dois ao mesmo tempo
9. O resultado aparece pra ambos
10. Usem o chat normalmente

---

## Observações

- O servidor é em memória. Se ninguém ficar na sala por um tempo e o Replit “dormir”, a sala some (é normal em plano grátis).
- Funciona melhor se os dois entrarem e ficarem com a aba aberta.
- Você pode editar as ordens no arquivo `server.js` (procure por `maleOrders` e `femaleOrders`).
